# Phishing Detection & Awareness Report

A portfolio-ready report explaining phishing indicators, example classifications, email-header analysis, business risk, and prevention guidelines.

## Important disclaimer
This is an **educational sample** with fictional email examples and reserved example domains. No real mailbox, headers, or public dataset was analyzed. Do not present these examples as real incidents. Replace or supplement them only with public samples whose licenses permit reuse or with samples you are authorized to analyze. Sanitize personal and confidential information before publication.

## Included files
- `Phishing_Detection_Awareness_Report.pdf` — professionally formatted report with original illustrations
- `email_examples.csv` — editable synthetic examples and classifications
- `assets/` — report illustrations

## Topics covered
- Safe / Suspicious / Phishing classification
- Spoofed senders, look-alike domains, urgency, credential requests, and attachments
- From, Reply-To, Return-Path, Received, SPF, DKIM, and DMARC header review
- Business-friendly risk explanation
- User prevention guidance and incident response
- Safe evidence handling and privacy considerations
